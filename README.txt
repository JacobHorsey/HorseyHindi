HORSEY HINDI — iPHONE INSTALLATION

1. Create a PUBLIC GitHub repository (e.g. horsey-hindi-app).
2. Upload ALL files inside this folder to the repository ROOT, including index.html, sw.js, manifest.webmanifest and the icons.
3. In repository Settings > Pages choose Deploy from a branch, main, /(root), and Save.
4. Open https://YOUR-USERNAME.github.io/horsey-hindi-app/ in Safari on iPhone.
5. Tap Share > Add to Home Screen > Add.

The standalone index.html contains the course and embedded audio. A Hindi system voice is required for spoken text. Browser autoplay policies may prevent audio until first interaction.

If replacing an existing deployment, update all files and allow Pages to redeploy. Installing under a NEW URL starts with separate local progress.
